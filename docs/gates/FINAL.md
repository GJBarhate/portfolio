# Where this stands

PLAN.md described 52 weeks of work across nine phases. This records what was
actually built, what was measured, and what was not done — because the value
of a gate document is entirely in whether it tells the truth about the second
and third of those.

## Closed, with evidence

**All seven P0 defects.** See `PHASE-0.md`. The two the site was reported
broken on — the command palette being unopenable on a phone (D-01) and the
`window.forge` CLI being console-only (D-02) — are closed and asserted by
tests that fail if either regresses.

**The Phase 1 system layer.** Five modules, each the single source of truth
for one axis, each with a script that fails the build on drift. See
`PHASE-1.md` for the measured results: zero overflow across 456 checked
states, zero text below 12px, zero raw-px media preludes, 60/60 contrast role
pairs, zero touch targets under 44px with no overlapping hit boxes.

**The Phase 2 correctness and resilience work.** See `PHASE-2.md`. A failed
lazy chunk degrades one section; a lost WebGL context recovers twice and then
falls back; a throwing `localStorage` and a corrupt store payload both leave
the page working; the CSP is enforced with build-gated inline hashes.

**The Phase 4 *system*, not its content.** See `PHASE-4.md`. The registry, the
cost gate, the tier contract and the choreography scaffolding exist and are
enforced; the new effects they were built to govern do not.

## Measured, and honest about it

`docs/baseline/2026-08.md` is generated by a script, not written by hand, and
it records failures as readily as successes:

- LCP 2.1–2.3 s on the throttled profile against a 1.8 s target — **not met**
- CLS bimodal at ~0.0005 or ~0.257 against a 0.02 target — **not met**, with
  the cause traced (`.hero-copy` reflowing when the deferred stylesheet
  applies), five remedies tried, four kept and one reverted with its number
- Critical CSS 35.8 KB against a 14 KB target — **not met**, blocked on T-050
- Long tasks ~50 over a full load and scroll against ≤ 1 — **not met**

Every one of those is blocked on the same unstarted task: **T-050, splitting
the 4,755-line stylesheet by when it is needed.** That is the highest-value
remaining work in the plan, and the baseline says so with numbers rather than
with an opinion.

## Not done

| Phase | Task | Why not |
|---|---|---|
| P3 | **T-050** split the stylesheet | the single biggest remaining lever; blocks three failing metrics |
| P3 | **T-053** remove or shrink `three` | 128.3/135 KB — green but tight; needs a prototype of the two islands in raw WebGL |
| P3 | **T-054** remove `framer-motion` | imported by 38 components; a one-pass removal is a large regression risk that the visual baselines now make survivable, but it is a project of its own |
| P3 | **T-055** INP work | needs field data or an interaction harness; the lab proxy in the baseline is dominated by chunk fetch time |
| P4 | **T-061–T-068, T-070** | the effect *content*: scroll-driven migration, card morph transitions, the shader library, the second-generation background, typographic motion, the cursor system, choreography, micro-interactions |
| P5 | **T-080–T-087** | case studies, the lab, the notes section, per-route SEO. These are **writing**, not engineering: five case studies and six posts about this author's own work, which nobody else can honestly draft |
| P6 | **T-091–T-095** | prerendering, the API layer, the content pipeline, edge caching. `docs/adr/001-framework.md` records the decision to defer this and the conditions that would reopen it |
| P7 | **T-100–T-103** | the WebGPU tier |
| P8 | **T-110–T-113** | the final audit on real devices, awards submissions, the launch. `docs/maintenance.md` covers the sustaining half |

Three things in the plan cannot be done from a repository at all and are
recorded rather than pretended:

- **Buying `gauravbarhate.dev`.** `src/lib/siteConfig.js` points at the origin
  that is actually served, and switching it is a one-line change plus the
  Vercel redirect. A canonical URL is a statement of fact, not of intent.
- **A real screen-reader pass.** `docs/a11y/sr-transcript.md` records exactly
  what is verified automatically and what still needs VoiceOver and NVDA.
- **Real-device and field measurement.** RUM is installed and reporting; it
  needs traffic and time.

## The one-line version

The site's reported bugs are fixed and tested, the systems that prevent that
class of bug are in place and enforced by nine CI jobs, and the performance
work has an honest measured baseline that says which four targets are still
missed and which single task unblocks them.

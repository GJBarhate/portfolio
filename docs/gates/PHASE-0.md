# Phase 0 gate — stop the bleeding

**Exit condition:** every P0 defect closed and provable.

| Defect | Status | Evidence |
|---|---|---|
| **D-01** The command palette can never be opened on a touch device | closed | One canonical channel, `forge:open-palette`. Three doors dispatch it: a header button visible at every width, the first row of the drawer, and ⌘K. `tests/palette.spec.js` asserts all three, and asserts touch operability with no keyboard. |
| **D-02** `window.forge` is console-only | closed | `src/lib/forgeCli.js` is one registry with two front-ends: the console shim (unchanged for the visitor) and the palette's `>` terminal mode. `tests/cli.spec.js` runs every command from the palette on a 390px touch viewport. `App.jsx` is 60+ lines shorter. |
| **D-03** The ARCADE dropdown has never rendered | closed | `group` added; also opens on `:focus-within`; `pointer-events` enabled only while open; five `<button role="menuitem">` rows each launching their own game; the whole panel gated behind `(hover: hover) and (pointer: fine)`. `tests/nav.spec.js -g "arcade dropdown"`. |
| **D-04** Source files are encoding-corrupted | closed | 5 BOMs stripped, 21 mojibake sequences repaired. `scripts/check-encoding.mjs` runs in `prebuild` and fails on either. `.editorconfig` and `.gitattributes` stop it recurring. |
| **D-05** The sitemap advertises a domain the site does not serve | closed | `src/lib/siteConfig.js` is the one origin; `index.html` takes it through a Vite plugin, `scripts/gen-sitemap.mjs` writes the sitemap and robots.txt from it, and `scripts/check-canonical.mjs` fails the build if more than one first-party origin appears in the output. |
| **D-06** The visual-regression CI job cannot pass | closed | `@playwright/test` is a real pinned dependency; `playwright.config.js` is 16 projects covering the §3.2 device matrix plus reduced-motion, forced-colors, light-scheme, no-js and WebKit; CI installs and runs the real runner, sharded three ways. |
| **D-07** The ambient shader mounts on phones with no measured evidence | closed | `src/lib/deviceProfile.js`: five proxies plus a real off-screen micro-benchmark of the actual shader, run after LCP and then at idle, cached per session. `useHeavyAmbientAllowed` is now `useDeviceTier() >= 2`. Tier ≤ 1 gets the CSS mesh, documented as the cheap version of a live page rather than a dead one. |

## Supporting work in this phase

- **T-008 · RUM.** `src/lib/rum.js` subscribes to LCP/INP/CLS/TTFB/FCP plus
  long tasks, attaches nine dimensions to every beacon, ships once per page
  view with `sendBeacon`, and carries errors from the boundary,
  `window.onerror` and `unhandledrejection` on the same channel. Dynamically
  imported at idle; not in the eager graph.
- **T-009 · Baseline.** `docs/baseline/2026-08.md`, generated by
  `scripts/measure-baseline.mjs` — CDP throttling at the Moto G Power profile,
  three runs per cell, medians, across all three themes and two device classes.
- **T-010 · One breakpoint source.** `src/styles/breakpoints.css` +
  `src/lib/breakpoints.js`, range syntax only, rem only.
  `scripts/check-breakpoints.mjs` reports zero raw-px preludes.
- **T-011 · `useIsMobile` deleted.** Three orthogonal hooks in
  `src/lib/useMedia.js`, all `matchMedia`-driven through
  `useSyncExternalStore`. Every `resize` listener in `src/` is gone, replaced
  by a `ResizeObserver` on the element that actually matters.
- **T-012 · Nav anchoring.** Header height published as `--header-h` from a
  ResizeObserver; `goTo()` uses it; active-section detection is the "last
  section past the header line" algorithm riding the existing once-per-frame
  scroll read; the URL hash follows, throttled, via `replaceState`.
- **T-013 · The mobile smoke suite.** Overflow, console errors, 44px hit
  areas, alt text, the 12px type floor, one `<h1>`, landmarks, request size.
